UMH Connector

WhatsApp & Telegram directly inside Odoo

The UMH Connector links Odoo with your Unified Messenger Hub instance - the central platform for WhatsApp Business API and Telegram bots. Open the right chat conversation directly from any customer contact with a single click.

WhatsApp Smart Button

One click on the WhatsApp button opens the customer chat in Unified Messenger Hub. Uses a dedicated WhatsApp number field - no accidental fallback to landlines that would waste Meta template fees.

Telegram Smart Button

For customers connected via Telegram, the button opens their chat using the stored Telegram Chat ID - without leaving the contact form.

Central URL Setting

Configure your UMH instance URL once under Settings > UMH Connector - it applies to all users across the entire Odoo instance.

New Fields on Contacts

  • WhatsApp Number - dedicated field, separate from Phone / Mobile
  • Telegram Chat ID - numeric ID from the UMH contact profile

The separate WhatsApp field prevents paid Meta templates from being sent to landline numbers that have no WhatsApp account.

Requirements

  • Odoo 17 Community or Enterprise
  • A running Unified Messenger Hub instance (messengerhub.de)
  • WhatsApp Business API or Telegram bot configured in UMH

Installation

  1. Install the module in Odoo (Technical mode > Apps)
  2. Go to Settings > UMH Connector and enter your UMH instance URL
  3. Open any customer contact and fill in the WhatsApp Number and/or Telegram Chat ID
  4. The Smart Buttons appear automatically at the top of the contact form
