UMH Connector

WhatsApp & Telegram directly inside Odoo

The UMH Connector links Odoo with your Unified Messenger Hub instance - the central platform for WhatsApp Business API and Telegram bots. Open the right chat conversation directly from any customer contact with a single click.

What Unified Messenger Hub offers

Unified Inbox

WhatsApp & Telegram messages in one shared inbox — no app switching.

Team Collaboration

Assign and take over conversations. Each agent sees their own queue.

ERP Integration

Connect Odoo or Dolibarr. Identify customers, create leads and quotes directly from chat.

Quick Reply Templates

Save frequently used texts as templates and insert them with one click.

Absence Auto-Responder

Automatic replies outside business hours — configurable per channel.

File & Image Sending

Send JPG, PNG and PDF files directly from the chat window.

Status Workflow

Track conversations through Open, In Progress, Quote Sent and Closed stages.

Real-Time Notifications

Browser and OS notifications so no incoming message goes unnoticed.

What this module adds to Odoo

  • WhatsApp Smart Button - opens the customer chat in UMH with one click
  • Telegram Smart Button - same for Telegram, using the stored Chat ID
  • WhatsApp Number field - dedicated field, separate from Phone / Mobile
  • Telegram Chat ID field - numeric ID from the UMH contact profile
  • Central URL setting - configure your UMH instance once for all users

The dedicated WhatsApp field prevents paid Meta templates from being sent to landlines without WhatsApp.

Requirements

  • Odoo 17 Community or Enterprise
  • A running Unified Messenger Hub instance (messengerhub.de)
  • WhatsApp Business API or Telegram bot configured in UMH

Installation

  1. Install this module in Odoo
  2. Go to Settings > UMH Connector and enter your UMH URL
  3. Add the WhatsApp Number / Telegram Chat ID on customer contacts
  4. Smart Buttons appear automatically on the contact form
